# Wave Accounting 自动化

> **注意：** Wave Accounting 工具包（`wave_accounting`）目前在 Composio 平台中没有可用的原生工具。搜索 Wave Accounting 专用工具时，返回的是其他会计/开票平台（Stripe、Zoho Invoice）的结果。

**工具包文档：** [composio.dev/toolkits/wave_accounting](https://composio.dev/toolkits/wave_accounting)

---

## 状态

此集成**尚未提供**原生 Wave Accounting 工具。当 Wave Accounting 工具在 Composio 中可用时，此技能文件将更新为真实的工具 slug、工作流和陷阱。

对于会计和开票自动化需求，可考虑以下目前可用的替代方案：
- **Stripe** -- 支付处理、开票和订阅管理
- **Zoho Invoice** -- 发票创建、付款跟踪和联系人管理
- **QuickBooks** -- 完整的会计套件，包含开票和费用跟踪
- **FreshBooks** -- 云会计，包含时间跟踪和开票

---

## 设置

1. 将 Composio MCP 服务器添加到你的客户端配置中：
   ```
   https://rube.app/mcp
   ```
2. 请稍后回来查看 Wave Accounting 集成的可用性。
