# 开发者关心的变更日志和产品更新

## 详细指南

在执行此技能前，阅读[详细指南](references/detailed-guide.md)。它保留了完整的程序和参考资料。将其安全性、先决条件和验证要求视为强制性的。对于专注工作，加载相关部分；对于端到端工作，完全阅读指南。

## 何时使用

当你需要创建开发者真正阅读和关心的发布说明和产品更新时使用此技能。此技能涵盖变更日志格式、版本管理通信、重大更改公告、弃用通知和为新功能构建期待。触发短语："changelog",...


发布说明是开发者通信，而不是文档。做好的话，它们建立信任、展示动力，并将更新转变为市场营销时刻。

## 限制

- 仅当任务明确与其上游源和本地项目上下文匹配时，才使用此技能。
- 在应用更改前验证命令、生成的代码、依赖、凭据和外部服务行为。
- 不要将示例视为环境特定测试、安全审查或用户批准破坏性或昂贵操作的替代品。
