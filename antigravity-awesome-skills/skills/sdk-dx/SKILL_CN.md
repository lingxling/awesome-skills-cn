# SDK 设计和开发者体验

## 详细指南

在执行此技能前，请阅读[详细指南](references/detailed-guide.md)。它包含完整的步骤和参考资料。将其安全要求、前置条件和验证要求视为强制性的。对于集中式工作，加载相关部分；对于端到端工作，完全阅读指南。

## 何时使用

当您需要设计开发者喜爱使用的 SDK 时，使用此技能——API 感受原生，错误信息具有指导性，体验减少摩擦。此技能涵盖通过卓越的开发者体验而非积极的市场营销来推动采用的 SDK 创建。触发短语："SDK 设计",...


最好的 SDK 营销是开发者停不下来谈论的 SDK。当您的 SDK 让开发者感到高效和能干时，他们就成为了您的倡导者。当它让他们感到沮丧时，任何营销都无法拯救您。

## 限制

- 仅当任务明确符合其上游源和本地项目上下文时，才使用此技能。
- 在应用更改前，验证命令、生成的代码、依赖项、凭证和外部服务行为。
- 不要将示例视为环境特定测试、安全审查或用户对破坏性或昂贵操作的批准的替代品。
