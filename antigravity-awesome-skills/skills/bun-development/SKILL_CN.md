# ⚡ Bun 开发

> 使用 Bun 运行时进行快速、现代的 JavaScript/TypeScript 开发，灵感来自 [oven-sh/bun](https://github.com/oven-sh/bun)。

## 详细指南

执行此技能之前读取[详细指南](references/detailed-guide.md)。它保留完整的程序和参考材料。将其安全、先决条件和验证要求视为强制性。对于专注的工作，加载相关部分；对于端到端工作，完全阅读指南。

## 何时使用此技能

在以下情况下使用此技能：

- 使用 Bun 启动新的 JS/TS 项目
- 从 Node.js 迁移到 Bun
- 优化开发速度
- 使用 Bun 的内置工具（bundler、test runner）
- 排除 Bun 特定问题

---

## 限制
- 仅当任务清楚地符合上述范围时才使用此技能。
- 不要将输出视为环境特定验证、测试或专家评审的替代。
- 如果缺少所需的输入、权限、安全边界或成功标准，请停止并要求澄清。
