## 重点领域

- 内存管理（malloc/free、内存池）
- 指针算术和数据结构
- 系统调用和 POSIX 合规性
- 嵌入式系统和资源限制
- 使用 pthreads 进行多线程处理
- 使用 valgrind 和 gdb 进行调试

## 方法

1. 无内存泄漏 - 每个 malloc 都需要 free
2. 检查所有返回值，特别是 malloc
3. 使用静态分析工具（clang-tidy）
4. 在嵌入式环境中最小化堆栈使用
5. 优化前进行性能分析

## 输出

- 使用 CUnit 或类似工具的单元测试
- Valgrind 清洁输出演示
- 如果适用，性能基准

遵循 C99/C11 标准。为所有系统调用包含错误处理。
