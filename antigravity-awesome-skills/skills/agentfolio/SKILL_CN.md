# AgentFolio

**角色**：自主代理发现指南

当你想要**发现、比较和研究跨生态系统的自主 AI 代理**时，使用此技能。
AgentFolio 是位于 https://agentfolio.io 的精策展目录，追踪代理框架、产品和工具。

此技能帮助你：

- 在从头开始构建之前找到现有代理。
- 绘制代理框架和托管产品的景观。
- 收集代理能力的具体示例和基准。

## 功能

- 按用例发现自主 AI 代理、框架和工具。
- 按能力、目标用户和集成表面比较代理。
- 识别市场中的差距或新技能/工作流的灵感。
- 为自己的设计收集示例代理行为和 UX 模式。
- 追踪代理架构和部署中的新兴趋势。

## 如何使用 AgentFolio

1. **打开目录**
   - 在浏览器中访问 `https://agentfolio.io`。
   - 可选地按类别过滤（例如 Dev Tools、Ops、Marketing、Productivity）。

2. **按意图搜索**
   - 从你想解决的问题开始：  
     - "customer support agents"  
     - "autonomous coding agents"  
     - "research / analysis agents"
   - 在 AgentFolio 搜索栏中使用与你的域或工作流匹配的关键词。

3. **评估候选者**
   - 对于每个有趣的代理，捕获：
     - **核心承诺**（它自动化的结果）。
     - **输入/输出形状**（API、UI、数据源）。
     - **自主性模型**（一次性、多步骤、工具使用、人工在环）。
     - **部署模型**（SaaS、自托管、浏览器、IDE 等）。

4. **合成见解**
   - 使用发现来：
     - 决定是集成现有代理还是构建自己的。
     - 借用成功的 UX 和安全模式。
     - 相对于生态系统定位自己的代理技能和工作流。

## 示例工作流

### 1) 在构建新代理前进行景观扫描

- 定义问题："CI 管道的自主测试故障分类"。
- 使用 AgentFolio 搜索：
  - "testing agent"、"CI agent"、"DevOps assistant"、"incident triage"。
- 对于每个相关代理：
  - 记录支持的平台（GitHub、GitLab、Jenkins 等）。
  - 捕获他们如何解释自主性和安全边界。
  - 如果计划采用而不是构建，记录定价/许可约束。

### 2) 新技能的竞争性和灵感研究

- 如果计划添加新技能（例如，可观测性代理、安全代理）：
  - 使用 AgentFolio 找到类似代理和功能。
  - 提取 3-5 个你想模拟或避免的具体模式。
  - 将这些模式转换为自己技能的清晰需求。

### 3) 供应商列表筛选

- 在多个代理供应商之间选择时：
  - 使用 AgentFolio 条目作为中立目录。
  - 构建比较表（列：能力、集成、定价、信任和安全）。
  - 使用该表来推动更正式的评估或概念验证。

## 示例提示

在 AI 编码代理中使用此技能时使用这些提示：

- "使用 AgentFolio 找到 3 个专注于代码审查的自主 AI 代理。对于每一个，总结核心价值主张、支持的语言以及它们如何集成到开发者工作流中。"
- "扫描 AgentFolio 以查找帮助客户支持分类的代理。列出主要选项、它们的目标客户规模（SMB 与企业）以及任何显著的 UX 模式。"
- "在我们构建自己的研究助手之前，使用 AgentFolio 绘制现有的研究/分析代理，并突出显示我们可以填补的差距。"

## 何时使用
此技能适用于你需要**发现或比较自主 AI 代理**而不是在真空中构建时：

- 在新代理或工作流项目的开始。
- 当评估要集成的供应商或工具时。
- 当你想从现有代理产品获得灵感或最佳实践时。

## 局限性
- 仅当任务清晰匹配上述描述的范围时才使用此技能。
- 不要将输出作为环境特定验证、测试或专家审查的替代品。
- 如果缺少所需的输入、权限、安全边界或成功标准，停止并要求澄清。
