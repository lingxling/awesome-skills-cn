# Android 应用开发技能

## 详细指南

在执行此技能之前，请阅读 [详细指南](references/detailed-guide.md)。它包含完整的流程和参考资料。将其安全性、先决条件和验证要求视为强制性的。为了专注工作，加载相关部分；为了端到端工作，请完整阅读指南。

- 在决定技术栈时使用（参见 §1 技术栈选择）
- 在设置项目架构时使用（参见 §2 架构）
- 在设计 UI、屏幕或设计系统时使用（参见 §3 UI 和设计）
- 在确保代码质量、模式或 API 时使用（参见最佳实践）

- 在规划测试策略时使用（参见 §6 测试）
- 在配置构建、CI/CD 或发布管道时使用（参见 §7 构建和发布）
- 在优化性能或内存时使用（参见 §8 性能）
- 在调试或修复错误时使用（参见 §9 调试）
- 在遵循完整开发路线图时使用（参见 §10 开发路线图）
- 在需要深度参考堆栈时使用（参见 `references/` 目录）

## 限制

- 此技能的范围限制于 Android 和 Android 相关交付路径；它不涵盖 iOS 特定架构、App Store 发布操作或 Apple 平台 UI 指导。
- 版本号、Play Console 政策阈值和推荐库可能会变更；在发货前针对当前 Android、Google Play 和库文档验证发布关键细节。
- 代码片段是架构模式，而不是完整应用；调整包名、依赖版本、权限、隐私披露和安全控制以匹配实际项目。
- 该指导不替代生产发布的设备 QA、可访问性审查、安全审查、法律/隐私审查或商店合规检查。
