# Bash 防御模式

使用防御性编程技术、错误处理和安全最佳实践来编写生产就绪 Bash 脚本的综合指导，以防止常见陷阱并确保可靠性。

## 何时使用此技能

- 编写生产自动化脚本
- 构建 CI/CD 管道脚本
- 创建系统管理实用程序
- 开发错误弹性部署自动化
- 编写必须安全处理边界情况的脚本
- 构建可维护的 shell 脚本库
- 实现全面的日志记录和监控
- 创建必须在不同平台上工作的脚本

## 何时不使用此技能

- 您需要单个临时 shell 命令，而不是脚本
- 目标环境需要严格的 POSIX sh
- 任务与 shell 脚本或自动化无关

## 说明

1. 确认目标 shell、操作系统和执行环境。
2. 从一开始就启用严格模式和安全默认值。
3. 验证输入、引用变量并安全处理文件。
4. 添加日志记录、错误陷阱和基本测试。

## 安全性

- 避免在没有确认或干运行标志的情况下执行破坏性命令。
- 除非严格必要，否则不要以 root 身份运行脚本。

有关详细模式、检查清单和模板，请参阅 `resources/implementation-playbook.md`。

## 限制

- 仅在任务明确符合上述范围时使用此技能。
- 不要将输出作为特定于环境的验证、测试或专家审查的替代品。
- 如果缺少所需的输入、权限、安全边界或成功标准，请停止并要求澄清。
