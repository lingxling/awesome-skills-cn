# Anthropic 品牌样式

## 概述

仅当用户要求该品牌时，才使用此捆绑的 Anthropic 专用样式参考。它是本地快照，不是实时权威品牌资产服务。

**关键词**：品牌、企业身份、视觉身份、后处理、样式、品牌颜色、排版、Anthropic 品牌、视觉格式、视觉设计

## 品牌指南

### 颜色

**主要颜色：**

- 深色：`#141413` - 主要文本和深色背景
- 浅色：`#faf9f5` - 浅色背景和深色文本
- 中灰色：`#b0aea5` - 次要元素
- 浅灰色：`#e8e6dc` - 微妙背景

**强调颜色：**

- 橙色：`#d97757` - 主要强调
- 蓝色：`#6a9bcc` - 次要强调
- 绿色：`#788c5d` - 第三强调

### 排版

- **标题**：Poppins（Arial 作为备用）
- **正文**：Lora（Georgia 作为备用）
- **说明**：字体应在你的环境中预装以获得最佳效果

## 功能

### 智能字体应用

- 对标题（24pt 及更大）使用 Poppins 字体
- 对正文使用 Lora 字体
- 如果自定义字体不可用，选择 Arial/Georgia 作为备用
- 验证实际导出格式中的可读性

### 文本样式

- 标题（24pt+）：Poppins 字体
- 正文：Lora 字体
- 基于背景的智能颜色选择
- 保留文本层次和格式

### 形状和强调颜色

- 非文本形状使用强调颜色
- 循环使用橙色、蓝色和绿色强调
- 保持视觉兴趣同时保持品牌一致性

## 技术细节

### 字体管理

- 可用时使用系统安装的 Poppins 和 Lora 字体
- 对 Arial（标题）和 Georgia（正文）使用文档化备用
- 无需安装字体 - 使用现有系统字体
- 为获得最佳效果，在你的环境中预装 Poppins 和 Lora 字体

### 颜色应用

- 使用 RGB 颜色值以实现精确的品牌匹配
- 通过 python-pptx 的 RGBColor 类应用
- 在目标应用程序中验证导出颜色

## 何时使用
用于用户明确要求的 Anthropic 品牌工件。保留不同的现有品牌，而不是全局应用这些颜色。本目录包含说明和许可证，而不是样式脚本或捆绑字体。

## 示例和先决条件
对于请求的幻灯片，检查已安装的字体，在实际编写工具中应用相关颜色并导出预览。如果 Poppins/Lora 不可用，公开选择的备用并检查换行和对比度。预期结果：可审查的品牌草稿，而不是自动字体安装或商标批准。
