# 处理 GitHub 注释

## 概述

使用 GitHub CLI（`gh`）有效处理 PR 审查注释或问题反馈。此技能确保所有反馈都被系统地处理。

## 前置条件

确保 `gh` 已认证。

```bash
gh auth status
```

如果未登录，运行 `gh auth login`。

## 工作流程

### 1. 检查注释

获取当前分支 PR 的注释。

```bash
gh pr view --comments
```

或使用可用的自定义脚本列出线程。

### 2. 分类和规划

- 列出注释和审查线程。
- 为每个提议修复。
- 如果有很多，**等待用户确认**要首先处理哪些注释。

### 3. 应用修复

应用所选注释的代码更改。

### 4. 回复注释

修复后，回复线程已解决。

```bash
gh pr comment <PR_NUMBER> --body "在最新提交中处理。"
```

## 常见错误

- **在不理解背景的情况下应用修复**：始终阅读注释周围的代码。
- **不验证认证**：在开始前检查 `gh auth status`。

## 何时使用

此技能适用于执行概述中描述的工作流程或操作。

## 限制条件

- 仅在任务明确符合上述描述的范围时使用此技能。
- 不要将输出视为环境特定验证、测试或专家评审的替代品。
- 如果缺少必需的输入、权限、安全边界或成功标准，请停止并寻求澄清。
