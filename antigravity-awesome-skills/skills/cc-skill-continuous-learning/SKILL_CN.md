# 从已完成会话进行持续学习

捕获一个可复用的经验教训，其触发、修复和验证可以在不保留私人谈话的情况下进行解释。输出是一个审查的程序，而不是自动的记忆更新。

## 何时使用
在解决故障、重复的项目特定更正或明确要求保存所学内容后使用。跳过一次性打字错误、未解决的猜测、短暂提供商故障和项目文档已涵盖的经验教训。仅长会话本身不能使经验教训可复用。

## 输入和先决条件

- 授权的会话摘要或记录、受影响的代码或配置，以及确认修复的命令或观察。
- 经验教训的范围：此存储库、此工具版本或更通用的程序。
- 现有的授权文档目的地。如果未要求保存，在对话中返回草稿；不要自动更新用户记忆、安装技能或修改代理配置。
- 可选的[会话长度帮助程序](evaluate-session.sh)需要 Bash 和 Python 3。其唯一设置是 [config.json](config.json) 中的 `min_session_length`。

## 程序

1. 识别失败的假设和最终观察到的行为。将失败的假设与验证的原因分开。
2. 检查当前源和测试结果。未曾尝试过的记忆修复保持为开放假设。
3. 说明狭隘的触发和先决条件。当修复取决于运行时或工具版本时包括它。
4. 写出最小序列来重现诊断并验证修复。包括预期结果和反例，其中不应使用该程序。
5. 删除机密、用户名、绝对个人路径、私有消息和无关的存储库详细信息。与复制记录相比，更倾向于最小合成示例。
6. 与现有说明进行比较。在授权时修改现有项目说明，而不是创建另一个重叠的技能。保留来源并区分原始观察与后来的泛化。
7. 呈现草稿及其证据。仅在用户已授权的范围内保存，然后读取保存的结果。

## 工作示例

说明性输入：React 测试在输入更改后、新异步验证完成前观察到旧的成功消息。修复将每个结果与确切的当前输入相关联；回归更改输入并声明过时的成功立即消失。

```text
触发：异步验证结果可以比它们描述的输入持续更长时间。
先决条件：组件存储输入和异步验证结果。
程序：将结果绑定到其输入；显示待处理状态直到该绑定
匹配；忽略来自被取代请求的结果。
验证：在验证待处理时将有效输入更改为无效输入。
预期：不显示先前的成功；最终错误属于新输入。
限制：这不建立验证本身的语义正确性。
```

记录真实经验教训时使用实际项目路径和测试输出。这是说明性模式，不是特定用户测试通过的声明。

## 可选会话长度提醒

```bash
bash skills/cc-skill-continuous-learning/evaluate-session.sh /absolute/path/to/session.jsonl
```

帮助程序计数其顶级 `type` 等于 `user` 的 JSONL 对象。它在配置的阈值后向 stderr 打印计数和审查提醒。它不提取模式、调用模型、创建目录或保存任何东西。`CLAUDE_TRANSCRIPT_PATH` 是可选的调用者提供的回退；不假设任何主机来填充它。此技能未配置自动钩子集成。

## 限制
- 记录格式在不同客户端之间有所不同。其他消息架构需要显式适配器；零消息不证明没有发生有用的工作。
- 帮助程序拒绝链接、非常规文件、无效 JSONL、超过 16 MiB 的文件和超过 1 MiB 的行。它永远不会打印记录内容。
- 成功的长度检查不是语义审查、隐私审查或保留经验教训的授权。
- 重新使用前重新检查版本特定的经验教训。不要在没有其他证据的情况下将项目变通方法提升为通用指令。
