# AI 代理开发工作流

## 概述

用于构建 AI 代理的专门工作流，包括单一自主代理、多代理系统、代理编排、工具集成和人工在环模式。

## 何时使用此工作流

在以下情况下使用此工作流：
- 构建自主 AI 代理
- 创建多代理系统
- 实现代理编排
- 向代理添加工具集成
- 设置代理记忆

## 工作流阶段

### 第 1 阶段：代理设计

#### 要调用的技能
- `ai-agents-architect` - 代理架构
- `autonomous-agents` - 自主代理模式

#### 操作
1. 定义代理目的
2. 设计代理功能
3. 规划工具集成
4. 设计记忆系统
5. 定义成功指标

#### 复制粘贴提示
```
使用 @ai-agents-architect 设计 AI 代理架构
```

### 第 2 阶段：单代理实现

#### 要调用的技能
- `autonomous-agent-patterns` - 代理模式
- `autonomous-agents` - 自主代理

#### 操作
1. 选择代理框架
2. 实现代理逻辑
3. 添加工具集成
4. 配置记忆
5. 测试代理行为

#### 复制粘贴提示
```
使用 @autonomous-agent-patterns 实现单代理
```

### 第 3 阶段：多代理系统

#### 要调用的技能
- `crewai` - CrewAI 框架
- `multi-agent-patterns` - 多代理模式

#### 操作
1. 定义代理角色
2. 设置代理通信
3. 配置编排
4. 实现任务委派
5. 测试协调

#### 复制粘贴提示

1. 设计工作流图
2. 实现状态管理
3. 添加条件分支
4. 配置持久化
5. 测试工作流

- `tool-design` - 工具设计

2. 设计工具界面
