# D3.js 可视化

## 详细指南

在执行此技能前，阅读[详细指南](references/detailed-guide.md)。它保留了完整的程序和参考资料。将其安全性、先决条件和验证要求视为强制性的。对于专注工作，加载相关部分；对于端到端工作，完全阅读指南。

## 何时使用 d3.js

**使用 d3.js 用于：**
- 需要唯一的视觉编码或布局的自定义可视化
- 具有复杂平移、缩放或刷新行为的交互式探索
- 网络/图表可视化（力导向布局、树图、层次结构、弦图）
- 具有自定义投影的地理可视化
- 需要平滑、精编过渡的可视化
- 具有细粒度样式控制的出版质量图形
- 标准库中不可用的新奇图表类型

**考虑替代方案用于：**
- 3D 可视化 - 改用 Three.js
