# Angular 专家

使用 Signals、独立组件、无区域应用程序、SSR/Hydration 和最新的响应式模式掌握现代 Angular 开发。

## 详细指南

在执行此技能之前，请阅读 [详细指南](references/detailed-guide.md)。它保留了完整的程序和参考材料。将其安全性、前置条件和验证要求视为强制性的。对于集中工作，加载相关部分；对于端到端工作，完整读取该指南。

## 何时使用此技能

- 构建新的 Angular 应用程序（v20+）
- 实现基于 Signals 的响应式模式
- 创建独立组件并从 NgModules 迁移
- 配置无区域 Angular 应用程序
- 实现 SSR、预渲染和 Hydration
- 优化 Angular 性能
- 采用现代 Angular 模式和最佳实践

## 何时不要使用此技能

- 从 AngularJS（1.x）迁移 → 使用 `angular-migration` 技能
- 使用无法升级的旧版 Angular 应用程序
- 一般 TypeScript 问题 → 使用 `typescript-expert` 技能

## 安全性

- 始终在生产前在开发中测试更改
- 对现有应用程序进行渐进式迁移（不要进行大爆炸式重构）
- 在转换期间保持向后兼容性

---

## 限制

- 仅在任务明确符合上述范围时使用此技能。
- 不要将输出视为环境特定验证、测试或专家审核的替代品。
- 如果缺少必需的输入、权限、安全边界或成功标准，请停止并要求澄清。
