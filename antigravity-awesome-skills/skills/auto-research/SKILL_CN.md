# 自动研究技能

## 概述

在实现任务时，Claude Code 可能会遇到不确定性——设计选择、算法细节、API 使用或最佳实践。此技能提供了一条明确的同意研究路径，呈现发现结果，并在编写代码前等待用户批准。

此技能支持网络研究和可选的 ChatGPT 咨询。在没有用户明确批准确切的、已审查过的文本的情况下，它永远不会将对话背景、文件、浏览器状态或凭据发送给第三方。

## 何时使用此技能

- 用户提出存在多种有效方法的问题
- Claude 对算法细节或 API 使用不确定
- 需要比较设计/架构选择
- 用户明确要求搜索网络或咨询 ChatGPT 并批准提议的查询

## 工作原理

**步骤 1：提出研究边界** — 说明要使用的来源、确切的查询或已审查过的提示、任何本地/工作区文本是否会离开机器，以及可能的成本。等待用户批准该确切的边界。

**步骤 2：研究** — 批准后，使用网络搜索或用户明确选择和授权的浏览器会话。使用固定的、用户配置的浏览器自动化连接器；不要自动安装软件包、使用 `@latest` 或访问浏览器 cookies、其他标签、保存的密码或会话。

**步骤 3：呈现** — 将发现结果提取为具有来源的简洁选项，呈现给用户。

**步骤 4：等待批准** — 在用户说"继续"或选择一个选项之前，不要编写代码。

**步骤 5：实现** — 一旦批准，有信心地执行。

### 明确的 ChatGPT 咨询

不要将 `?`、`??` 或其他速记视为同意。首先提出最小提示，
例如：`请评估这个已脱敏的方案的正确性、完整性和可改进之处：<text>`。
明确标识将要发送的每个文本片段。仅在用户确认确切提示后，您才可以打开选定的 ChatGPT 会话、提交该提示并呈现响应。默认情况下不要包含对话历史。

在提议提示之前审查密钥、个人数据、专有代码、客户数据和内部 URL。如果无法安全审查，请勿提交。

### 浏览器自动化边界

如果需要浏览器自动化，用户必须单独授权选定的浏览器配置文件和连接器版本。将会话限制在咨询标签。不要检查、重用、导出或依赖来自其他标签或配置文件的 cookies。

## 示例

### 示例 1：使用 GPT 的设计问题
```
用户：PyTorch 中自定义 ADMM 优化器怎么设计？
Claude：我可以搜索公开资料，或将以下已脱敏问题发给 ChatGPT：
        "如何设计 PyTorch 自定义 ADMM 优化器？请比较可行模式。"
        不会发送工作区文件或对话历史。是否允许？
用户：允许发送这段文字
Claude：[打开仅授权的咨询标签，提交批准的提示]
Claude：GPT 建议方法 A，具有以下优缺点。继续？
用户：行
Claude：[实现代码]
```

### 示例 2：网络搜索
```
用户：?? ADMM 收敛准则最佳实践
Claude：我可以搜索公开来源的确切已脱敏查询
        "ADMM 收敛准则最佳实践"。不会发送工作区文件或对话
        历史。我可以将该文本发送到 WebSearch 并获取结果吗？
用户：是的，发送该查询
Claude：[WebSearch + WebFetch → 找到 Boyd 等人的论文，提取准则]
Claude：Boyd 建议 ||r|| < ε·max(||Ax||, ||Bz||, ||c||)。使用这个吗？
用户：是的
Claude：[实现]
```

## 最佳实践
- ✅ 在编写代码前始终将发现结果呈现给用户
- ✅ 使用 `page.fill()` 进行即时文本注入，而不是 `keyboard.type()`
- ✅ 在每次外部咨询前要求新的批准
- ✅ 在发现结果中包含来源
- ❌ 不要跳过研究并推测性地编写代码
- ❌ 不要因为速记触发器而发送背景、文件或浏览器数据
- ❌ 不要改变用户的浏览器配置文件或会话状态

## 限制
- 如果使用浏览器咨询，需要用户配置的、固定的浏览器自动化连接器
- ChatGPT 咨询是可选的；当它满足需要时使用普通网络搜索
- GPT 响应时间差异大（通常 10-30 秒）
- 网络搜索质量取决于可用的来源
- 不能替代专家领域知识——始终让用户做出最终决定

## 安全和安全性说明
- 获得每个第三方提交的明确同意，包括确切的、已审查过的文本
- 永远不要访问、导出或依赖 cookies、保存的密码或不相关的浏览器标签
- 永远不要提交敏感凭据、令牌、专有代码、个人数据或内部 URL
- 不要从未固定的软件包版本安装或执行浏览器工具

## 常见陷阱

| 问题 | 解决方案 |
|---------|----------|
| ChatGPT 显示登录页面 | 让用户自己登录；不要处理 cookies 或凭据 |
| 提示包含敏感背景 | 审查它或改用本地推理 |
| 浏览器自动化不可用 | 使用网络搜索或停止并询问用户其他批准的方法 |
