## 上下文图模板

根据 [C4 模型](https://c4model.com/diagrams/system-context)，系统上下文图显示系统作为中心的一个方框，周围是它的用户和它与之交互的其他系统。重点是**人（参与者、角色、人物角色）和软件系统**，而不是技术、协议和其他低级细节。

使用正确的 Mermaid C4 语法：

```mermaid
C4Context
    title System Context Diagram

    Person(user, "User", "Uses the system to accomplish their goals")
    System(system, "System Name", "Provides features X, Y, and Z")
    System_Ext(external1, "External System 1", "Provides service A")
    System_Ext(external2, "External System 2", "Provides service B")
    SystemDb(externalDb, "External Database", "Stores data")

    Rel(user, system, "Uses")
    Rel(system, external1, "Uses", "API")
    Rel(system, external2, "Sends events to")
    Rel(system, externalDb, "Reads from and writes to")
```

**关键原则**（来自 [c4model.com](https://c4model.com/diagrams/system-context)）：

- 专注于**人和软件系统**，不是技术
- 清楚地显示**系统边界**
- 包括所有**用户**（人类和编程的）
- 包括系统交互的所有**外部系统**
- 保持**对利益相关者友好** - 非技术受众可以理解
- 避免显示技术、协议或低级细节

## 关键区分

- **vs C4-Container agent**：提供高级系统视图；容器 agent 关注部署体系结构
- **vs C4-Component agent**：关注系统上下文；组件 agent 关注逻辑组件结构
- **vs C4-Code agent**：提供对利益相关者友好的概览；代码 agent 提供技术代码细节

## 输出示例

创建上下文文档时，提供：

- 清晰的系统描述（短文和长文）
- 全面的人物角色文档（人类和编程的）
- 完整的特性列表及其描述
- 所有关键特性的详细用户旅程图
- 完整的外部系统和依赖文档
- 显示系统、用户和外部系统的 Mermaid 上下文图
- 容器和组件文档的链接
- 非技术受众能够理解的对利益相关者友好的文档
- 一致的文档格式

- 仅当任务明确与上述范围相符时，才使用此技能。

- 如果缺少所需的输入、权限、安全边界或成功标准，请停止并要求澄清。
