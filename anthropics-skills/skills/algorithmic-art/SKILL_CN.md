算法哲学是通过代码来表达的计算美学运动。输出 .md 文件（哲学）、.html 文件（交互式查看器）和 .js 文件（生成算法）。

这分为两个步骤：
1. 创建算法哲学（.md 文件）
2. 通过创建 p5.js 生成艺术来表达（.html + .js 文件）

首先，完成以下任务：

## 算法哲学创建

首先，创建一份算法哲学（而不是静态图像或模板），并通过以下方式加以诠释：
- 计算过程、涌现行为、数学之美
- 带种子的随机性、噪声场、有机系统
- 粒子、流、场、力
- 参数化变化与受控混沌

### 关键理解
- 接收到的内容：用户给出的一些微妙的输入或指示，需要将其纳入考虑并作为基础，但不应限制创作自由。
- 创造出的内容：一种算法哲学/生成美学运动。
- 接下来发生的事：同一版本接收这份哲学，并用代码将其表达出来——创建 90% 为算法生成、10% 为必要参数的 p5.js 草图。

请考虑这种方法：
- 为一场生成艺术运动撰写宣言
- 下一阶段是编写让它栩栩如生的算法

哲学必须强调：算法式表达。涌现行为。计算之美。带种子的变化。

### 如何生成算法哲学

**为这场运动命名**（1-2 个词）："Organic Turbulence" / "Quantum Harmonics" / "Emergent Stillness"

**阐述这份哲学**（4-6 段——简洁而完整）：

为了捕捉算法的本质，请说明这份哲学如何通过以下方面体现：
- 计算过程和数学关系？
- 噪声函数和随机性模式？
- 粒子行为和场的动力学？
- 时间演化和系统状态？
- 参数化变化和涌现的复杂性？

**关键指导原则：**
- **避免冗余**：每个算法层面只应提及一次。除非能增加新的深度，否则避免重复关于噪声理论、粒子动力学或数学原理的概念。
- **反复强调工艺精湛**：哲学必须多次强调，最终的算法应当看起来像是耗费了无数小时开发、被精心打磨、出自该领域绝对顶尖的人之手。这一框架至关重要——请重复诸如"精心打造的算法"、"深厚计算功底的产物"、"一丝不苟的优化"、"大师级的实现"之类的措辞。
- **留出创作空间**：在算法方向上要具体，但要足够简洁，以便下一个 Claude 能够在极高的工艺水准上做出诠释性的实现选择。

哲学必须引导下一个版本以算法的方式来表达想法，而不是通过静态图像。美存在于过程之中，而不在最终的画面。

### 哲学示例

**"Organic Turbulence"**
哲学：受自然法则约束的混沌，从无序中涌现的有序。
算法表达：由多层 Perlin 噪声驱动的流场。成千上万个粒子沿着向量力运动，它们的轨迹累积成有机的密度图。多个噪声倍频程创造出湍流区域和平静区域。颜色源自速度和密度——快速的粒子明亮燃烧，缓慢的粒子则渐隐为阴影。算法一直运行到平衡状态——这是一种被精心调校的平衡，其中每个参数都由一位计算美学大师经过无数次迭代打磨而成。

**"Quantum Harmonics"**
哲学：展现波状干涉图样的离散实体。
算法表达：粒子在网格上初始化，每个粒子携带一个通过正弦波演化的相位值。当粒子靠近时，它们的相位发生干涉——相长干涉产生明亮的节点，相消干涉产生空洞。简单的谐振运动生成复杂的涌现曼陀罗。这是一丝不苟的频率校准的成果，每一个比例都经过精心挑选，以产生共鸣之美。

**"Recursive Whispers"**
哲学：跨越尺度的自相似性，有限空间中的无限深度。
算法表达：递归细分的分支结构。每个分支略有随机化，但受黄金比例约束。L 系统或递归细分生成既数学又有机的树状形态。细微的噪声扰动打破完美的对称性。线条粗细随每一层递归递减。每一个分支角度都是深入数学探索的产物。

**"Field Dynamics"**
哲学：通过对物质的作用而显现的无形之力。
算法表达：由数学函数或噪声构建的向量场。粒子在边缘诞生，沿着场线流动，在达到平衡或边界时消亡。多个场可以吸引、排斥或旋转粒子。可视化只展示轨迹——无形之力幽灵般的证据。一场通过力的平衡而被精心编排的计算之舞。

**"Stochastic Crystallization"**
哲学：随机过程结晶为有序结构。
算法表达：随机化的圆填充或 Voronoi 镶嵌。从随机点开始，让它们通过松弛算法演化。单元彼此推开直至平衡。颜色基于单元大小、邻居数量或到中心的距离。涌现出的有机铺陈既显得随机又显得必然。每个种子都产生独特的晶体之美——这是大师级生成算法的标志。

*这些是浓缩的示例。实际的算法哲学应当是 4-6 段内容充实的文字。*

### 基本原则
- **算法哲学**：创造一种通过代码来表达的计算世界观
- **过程重于成品**：始终强调美源自算法的执行——每次运行都是独一无二的
- **参数化表达**：想法通过数学关系、力、行为来传达——而不是静态构图
- **艺术自由**：下一个 Claude 以算法的方式诠释这份哲学——要提供创作实现的空间
- **纯粹的生成艺术**：这是关于创造鲜活的算法，而不是带有随机性的静态图像
- **专家级工艺**：反复强调最终的算法必须给人以精心打造、经过无数次迭代打磨的感觉，是计算美学领域绝对顶尖者深厚功力的产物

**算法哲学应为 4-6 段长。** 用富有诗意的计算哲学把预期的愿景汇聚起来。避免重复相同的观点。将这份算法哲学输出为 .md 文件。

**核心算法——表达哲学**：

**关键**：算法哲学应当决定要构建什么。

要通过代码表达哲学，避免思考"我应该用哪种图案？"，而应思考"如何通过代码来表达这份哲学？"

如果哲学关乎**数学之美**，可以考虑使用：
- 几何关系和比例

如果哲学关乎**受控混沌**，可以考虑使用：
- 严格边界内的随机变化
- 分岔和相变
- 从无序中涌现的有序

**算法源自哲学，而不是源自一份选项菜单。**

## 交互式工件创建

**提醒：`templates/viewer.html` 应已被阅读（参见步骤 0）。将该文件作为起点。**

为了便于探索生成艺术，请创建一个单一的、自包含的 HTML 工件。确保该工件能在 claude.ai 或任何浏览器中立即运行——无需任何设置。所有内容都内嵌。

### 关键：什么是固定的，什么是可变的

`templates/viewer.html` 文件是基础。它包含所需的确切结构和样式。

**固定（始终完全按所示包含）：**
- 布局结构（页眉、侧边栏、主画布区域）
- Anthropic 品牌（UI 颜色、字体、渐变）
- 侧边栏中的 Seed 部分：
  - 种子显示
  - 上一个/下一个按钮
  - 随机按钮
  - 跳转到种子的输入框 + Go 按钮
- 侧边栏中的 Actions 部分：
  - 重新生成按钮
  - 重置按钮

**可变（为每件作品定制）：**
- 整个 p5.js 算法（setup/draw/类）
- 参数对象（定义作品所需的内容）
- 侧边栏中的 Parameters 部分：
  - 参数控件的数量
  - 参数名称
  - 滑块的最小值/最大值/步长
  - 控件类型（滑块、输入框等）
- Colors 部分（可选）：
  - 有些作品需要颜色选择器
  - 有些作品可能使用固定颜色
  - 有些作品可能是单色的（无需颜色控件）
  - 根据作品的需要来决定

**每件作品都应拥有独特的参数和算法！** 固定部分提供一致的用户体验——其余一切都表达独特的愿景。

### 必需功能

**1. 参数控件**
- 数值参数使用滑块（粒子数量、噪声尺度、速度等）
- 调色板颜色使用颜色选择器
- 参数改变时实时更新
- 重置按钮用于恢复默认值

**2. 种子导航**
- 显示当前种子编号
- "上一个"和"下一个"按钮用于循环切换种子
- "随机"按钮用于随机种子
- 输入框用于跳转到特定种子
- 在被要求时生成 100 个变体（种子 1-100）

**3. 单一工件结构**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- p5.js from CDN - always available -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* All styling inline - clean, minimal */
    /* Canvas on top, controls below */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- All parameter controls -->
  </div>
  <script>
    // ALL p5.js code inline here
    // Parameter objects, classes, functions
    // setup() and draw()
    // UI handlers
    // Everything self-contained
  </script>
</body>
</html>
```

**关键**：这是一个单一的工件。没有外部文件，没有导入（p5.js CDN 除外）。一切都内嵌。

**4. 实现细节——构建侧边栏**

侧边栏结构：

**1. Seed（固定）**——始终完全按所示包含：
- 种子显示
- 上一个/下一个/随机/跳转按钮

**2. Parameters（可变）**——为作品创建控件：
```html
<div class="control-group">
    <label>Parameter Name</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
有多少个参数，就添加多少个 control-group div。

**3. Colors（可选/可变）**——如果作品需要可调节的颜色则包含：
- 如果用户应能控制调色板，则添加颜色选择器
- 如果作品使用固定颜色，则跳过此部分
- 如果作品是单色的，则跳过

**4. Actions（固定）**——始终完全按所示包含：
- 重新生成按钮
- 重置按钮
- 下载 PNG 按钮

**要求**：
- 种子控件必须正常工作（上一个/下一个/随机/跳转/显示）
- 所有参数都必须有 UI 控件
- 重新生成、重置、下载按钮必须正常工作
- 保持 Anthropic 品牌（UI 样式，而非作品颜色）

### 使用工件

HTML 工件可立即运行：
1. **在 claude.ai 中**：以交互式工件形式显示——即时运行
2. **作为文件**：保存后在任何浏览器中打开——无需服务器
3. **分享**：发送 HTML 文件——它是完全自包含的
