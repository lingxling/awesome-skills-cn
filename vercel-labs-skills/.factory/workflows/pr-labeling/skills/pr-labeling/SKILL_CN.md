# 为 skills CLI 拉取请求添加标签

1. 使用触发消息中的编号调用 `read_pull_request`。读取标题、描述、
   当前标签以及变更文件的补丁。如果头提交（head commit）已不再与触发运行的提交一致，
   则停止，让更新的运行来进行分类。
2. 如果该拉取请求已经带有 `bug`、`documentation` 或 `enhancement` 标签，则停止。保留
   维护者或之前运行所选择的标签。
3. 根据补丁所支持的主要变更，选择一个标签：
   - `documentation`：仅修改文档、示例或说明性文字，不改变
     CLI 行为。
   - `bug`：修正现有的 CLI 行为，包括安装、更新检查、来源解析、
     代理检测或安全检查。
   - `enhancement`：新增或有意扩展 CLI 行为、命令、代理支持或
     集成支持。
4. 如果补丁被截断、内容混杂或不足以让你有把握地分类，则停止且不添加
   标签。不要仅凭标题推断标签。
5. 使用触发运行的拉取请求编号和所选标签，调用一次 `add_label`。
